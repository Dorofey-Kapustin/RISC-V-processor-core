# RISC-V-processor-core

### Описание проекта

В директории `CPU_RTL` представлены все необходимые RTL-файлы для сборки процессорного ядра и, на его основе, полноценной процессорной системы с интерфейсом внешней памяти. 

Данная система реализована на архитектуре **RISC-V** и поддерживает полный базовый набор инструкций, за исключением `LB`, `LBU`, `SB`, `LH`, `LHU`, `SH`. Отсутствие этих инструкций обусловлено тем, что блок Load/Store Unit (LSU) в настоящее время находится в стадии активной доработки.
